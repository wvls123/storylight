# Пример движка — Медвежонок Миша и упавшая звёздочка

Это **демонстрация техники**, не сюжет по умолчанию. Скилл (`../SKILL.md`) собирает **новую** книгу из запроса пользователя. Эта папка — открыть только если просят именно Мишу или нужно подсмотреть посадку/karaoke.

## Сюжет

1. У Миши погасла ночная звёздочка — без неё не звучит колыбельная.
2. В саду светлячок провожает его по дороге.
3. На поляне Миша сначала помогает зайчонку, потом бережно поднимает звёздочку.
4. Дома ставит её на полочку — свет и колыбельная возвращаются.

## Запуск

```bash
python -m http.server 8871
```

Открыть http://127.0.0.1:8871/

## Озвучка

```bash
pip install edge-tts
python scripts/generate_tts.py
```

Опционально локальный Qwen3-TTS: задайте `QWEN3_TTS_ROOT`. Ключи не используются.
