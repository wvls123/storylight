# Примеры для агента

## 1. Отдать эталон как есть

Пользователь: «запусти нашу интерактивную книгу».

```bash
cd book && python -m http.server 8871
```

Открыть http://127.0.0.1:8871/ . Не переписывать сюжет Миши.

## 2. Новая сказка на том же движке

Пользователь: «сделай такую же книгу про зайца и луну, 4 страницы».

1. Скопируй `book/` → `book-hare/` или правь JSON/билдеры в копии.
2. Заполни `pages.json` (бренд можно оставить «Лучик»).
3. Разбей `readText` на `words` с `d`. Грубая оценка: 0.18–0.28 служебные, 0.4–0.7 смысловые.
4. `python book/scripts/generate_tts.py` — появятся `audio/page-*.mp3` и `audio/word-*.mp3`.
5. Нарисуй или сгенерируй `assets/page-*.png` и иконки. Обнови пути.
6. Переименуй builders под сюжет, сохрани `seatBookOnTable` и комнату.
7. `python scripts/validate_kit.py --book book`.
8. Прогон в браузере: перелистни все страницы, «Читать мне», тап по слову, жест средней страницы.

## 3. Только переозвучить

Пользователь: «голос другой, текст тот же».

- Удали нужные `audio/*.mp3` и `audio/*.wav` (скрипт пропускает существующие).
- Поменяй `INSTRUCT` в `generate_tts.py` или голос `EDGE_VOICE`.
- Ключи не добавлять. Qwen — через `QWEN3_TTS_ROOT`.

## 4. Посадить книгу, если снова «провалилась в стол»

Симптом: книга в столешнице или висит в пустоте.

Проверь в `app.js`:

- стол добавлен в сцену с `name = "WoodenTable_01"`;
- после `loadFurniture` и `makeBook` вызывается `seatBookOnTable()`;
- пропсы через `sitOnY(obj, TABLE_TOP)`, не через угаданный `y`.

Не лечи это сменой камеры в ноль и не крась фон чёрным.

## 5. Поставить скилл агенту

```bash
git clone https://git.sr.ht/~horosheff/storylight %USERPROFILE%\.cursor\skills\storylight
```

или на UNIX:

```bash
git clone https://git.sr.ht/~horosheff/storylight ~/.cursor/skills/storylight
```

В корне клона должен лежать `SKILL.md`. После этого агент подхватывает скилл в новых чатах.
